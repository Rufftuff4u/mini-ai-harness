# Mini AI Coding Harness

A small educational project: local Jira-like ticket -> repository inspection -> AI coding -> tests -> optional draft GitHub PR.

## Requirements
- Python 3.10+
- Git
- OpenAI Codex CLI installed and authenticated (`codex --help` should work)
- Optional: GitHub CLI (`gh auth login`) and a GitHub remote for draft PR creation

Codex CLI availability, authentication, permissions and pricing depend on your account and environment. AI execution may incur usage costs. The app itself uses only the Python standard library.

## 1. Run baseline tests

```bash
python -m unittest discover -s tests -v
```

## 2. Initialize a repository

```bash
git init
git add .
git commit -m "Baseline mini order app"
```

Configure your Git identity if Git requests it. For a GitHub PR, create a GitHub repository and add it as `origin` before proceeding.

## 3. Run the harness

```bash
python harness.py ORDER-101
```

The script requires a clean working tree, creates `feature/order-101`, asks Codex to inspect the repo and implement the ticket, then independently runs tests. Review the diff and PLAN.md before approving.

## 4. Open a draft PR (optional)

After reviewing the changes and configuring a GitHub remote and `gh` authentication, you can manually commit/push/open a draft PR, or run a fresh harness execution with `--create-pr` from a clean baseline checkout:

```bash
python harness.py ORDER-101 --create-pr
```

Do not rerun on an existing feature branch; reset to a clean baseline first. The script opens a **draft** PR, never merges it.

## Safety

`codex exec --full-auto` allows workspace edits and command execution within Codex's configured sandbox. Run only in a disposable demo repository with no secrets. Inspect agent output, tests and diff before approving a PR. Passing tests does not prove correctness or security. The PR step requires a network connection and authenticated GitHub CLI.

## Architecture

- `tickets/ORDER-101.md`: fake Jira requirement and acceptance criteria
- `app/orders.py`: existing application
- `tests/test_orders.py`: baseline tests
- `AGENTS.md`: agent guidance / rules
- `harness.py`: orchestrator (Codex CLI + test runner + optional GitHub CLI)
- `PLAN.md`: generated by the coding agent

## Next enhancements

Replace local ticket with Jira API, add a deterministic requirements validator, require human plan approval, add coverage/security checks, create PRs through CI, and enforce branch protection. This is a learning demo, not an enterprise-safe production harness.
